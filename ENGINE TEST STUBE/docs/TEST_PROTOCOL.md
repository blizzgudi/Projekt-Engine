# Testprotokoll

1. Jedes Experiment hat eine eigene ID und einen eigenen Ordner.
2. Hypothese, Testbedingungen und Grenzen vor jedem Experiment dokumentieren.
3. Tests muessen wiederholbar sein. Python-Exitcode 0 ist erforderlich, aber nicht allein ein visueller Beweis.
4. Simulations-PASS, Rendering-PASS, Performance-PASS und Realphysik-PASS getrennt ausweisen.
5. Benchmarkdaten muessen Hardware, Gittergroesse, Schritte, Zeit und Speicher nennen. Keine GPU-Aussagen aus CPU-Tests ableiten.
6. Originaldateien von AI Game Studio, Silent Origin und anderen Projekten nicht veraendern. Neue Tests bleiben in ENGINE TEST STUBE.
7. Gescheiterte Versuche nicht als Erfolg deklarieren. Fehlgeschlagene Messungen und Grenzen protokollieren.
8. Material-Definitionen, Zellenstate, Verhalten und Renderer bleiben in der Architektur getrennt.
