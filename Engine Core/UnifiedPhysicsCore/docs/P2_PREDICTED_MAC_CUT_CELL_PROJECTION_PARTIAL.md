# P2 PARTIAL — Moving cut-cell projection of nonzero predicted MAC velocities (28.10.2026)

## Implemented bounded operator
`P2MovingBoxCutCellProjection3DBuilder::sample_with_predictor` accepts
staggered 3D predicted face velocities in m/s, alongside the exact old/new
axis-aligned translating-box geometry. It integrates the velocity over
the *time-averaged open face area*: `Q* = u* dt dx² aperture`.
The existing Jacobi-PCG weighted graph Laplacian now solves
`A phi = (alpha_old-alpha_new) dx³ - div(Q*)` per cell.
The corrected face-volume flux is `Q = Q* + aperture (phi_left-phi_right)`.
The legacy `sample` path remains a zero-predictor wrapper, with no
changes to the existing output semantics.

A predictor with incorrect array dimensions, nonfinite velocity,
nonzero outer-domain flux or nonzero blocked-face velocity is rejected.
A disconnected sealed component must satisfy its own compatibility
constraint. No input velocity arrays or box state are modified on
failure. Output pressure remains a gauge-relative pressure correction,
`rho phi/(dt² dx)`; pressure is not an absolute thermodynamic pressure.

## Native and independent verification
`tests/p2_moving_box_predictor_projection3d_tests.cpp` exercises
8³/12³/16³ grids, all axes, both translation directions and 0.25/0.5 m
displacements (36 moving cases). Each case superposes two independent
manufactured discrete vector fields near the domain corner:
- A four-face circulation with flux magnitude 0.02 m³ per face, which
  is exactly divergence-free and must survive the pressure projection.
- A six-face discrete gradient from a single cell potential of 0.03 m³,
  which must be eliminated by pressure projection. The independently
  calculated pressure difference is -480 Pa at density 1000 kg/m³,
  timestep 0.25 s and dx 1 m.

Every case checks the full 3D cell continuity equation, pressure
difference, predicted-curl preservation/gradient elimination and
saturated moving-cut-cell VOF conservation. Negative cases reject
nonfinite predictors, blocked faces, outer boundaries, wrong shapes
and invalid iteration budgets. The test inputs are unchanged on failure.

## Limitations and next steps
This is an **opt-in, one-step, constant-density closed-liquid pressure
projection**. The velocity predictor is externally supplied and not
yet generated by a time-resolved advection/viscosity/force integration
with moving solids. No free-surface pressure or stress conditions,
fluid-driven rigid-body trajectory, physical impulse/total-energy
closure, independent measured 3D CFD reference, or new UE5.8 Native-E2E
is established. The cut-cell pressure/VOF demonstration is saturated.
Partial free filling remains outside this test. A complete live
3D MAC/VOF predictor-corrector and bidirectional FSI validation
are still required. **P2–P8 remain PARTIAL.**
