# Projekt Engine

Zentraler Projektordner fuer die eigenstaendige, experimentelle Material- und Voxel-Engine.

## Ordner
- ENGINE TEST STUBE/ : aktive isolierte Experimente, Benchmarks, Test-Runner und Unreal 5.8 Testprojekt
- Materialdatenbank/ : zukuenftige Materialdefinitionen, Quellen und Importskripte
- Engine Core/ : zukuenftige engineunabhaengige Voxel-, Asset- und Materialsysteme
- Forschung/ : Forschungsunterlagen zu Materialphysik, Voxelverfahren und Rendering
- Dokumentation/ : Projektstruktur, Entscheidungen und Entwicklungsstand
